System Map

1. SourcesGOV.UK API, RSS feeds and YAML-configured listing pages.
2. CrawlPolite HTTP, per-source isolation, raw cache and URL dedupe.
3. ParseClean HTML/PDF text, classify sector, doc type and deadlines.
4. EmbedLocal vectors for search, with deterministic fallback if needed.
5. AnalyseLLM JSON when a key exists; pending placeholders when it does not.
6. ScoreOpportunity score, fee band and next action.
7. MatchCRM fit by sector, regulator and keywords.
8. DraftBriefings, proposals and outreach drafts only.
9. ReviewDashboard, digest, search and partner actions.

How To Teach It

Five-minute version

REGINT watches regulatory sources, turns publications into searchable evidence, scores commercial opportunities and drafts review material. Nothing is sent automatically.

  • Show the pipeline map.
  • Open the Today and Opportunities dashboard pages.
  • Explain the difference between pending analysis and paid LLM analysis.

Twenty-minute walkthrough

Run `make daily`, open the digest, search for a known topic, then trace one opportunity from publication to CRM match to outreach draft.

  • Use `price control cost of capital` as the search example.
  • Open the UKRN cost-of-capital result.
  • Ask what evidence a client would need before acting.

One-hour workshop

Assign roles: operator, reviewer and maintainer. The operator runs the job, the reviewer challenges outputs, and the maintainer patches one source or CRM row.

  • Operator checks counts and source failures.
  • Reviewer opens source links before trusting drafts.
  • Maintainer edits YAML, reruns tests and records decisions.

Safe Operating Rules

Use This Order

  • If you have copied information manually, paste it into Codex with the end-of-day prompt first.
  • Run `make daily` before reviewing anything current when you want a source refresh too.
  • Check source failures in the terminal and digest run notes.
  • Open source links before relying on a score or draft.
  • Use the dashboard status buttons to mark reviewed/actioned/dismissed.
  • Ask Codex to update YAML sources or CRM rows when something is stale.

Important Caveats

  • No API key means analysis rows are placeholders, not full model analysis.
  • Outreach is drafts-only. Nothing is sent by the tool.
  • Some public sites block or change markup. Fix selectors in `config/sources.yaml` first.
  • First crawls can be noisy. Use source links and dashboard review before client use.
